# Root Cause Analysis: Open redirect in auth callback

**RCA ID:** `RCA-20260730-002`
**Issue ID:** `ISS-20260730-002`
**Author:** Repair Agent
**Date:** 2026-07-30

---

## Summary

The `next` query parameter in the auth callback route was used directly in a redirect URL without validation, allowing an attacker to craft a phishing redirect.

**Root Cause Category:** `validation`

---

## 5 Whys Analysis

| Why # | Question | Answer |
|-------|----------|--------|
| 1 | Why can an attacker redirect users to an external site? | The `next` parameter is used verbatim in `NextResponse.redirect()` |
| 2 | Why isn't `next` validated? | Added as convenience without security review |
| 3 | Why was security review skipped? | Auth callback treated as plumbing, not security boundary |
| 4 | Why wasn't it identified as a security boundary? | No security review checklist existed for redirect params |
| 5 | Why was there no checklist? | No security coding standards were defined for the project |

**Root cause:** The auth callback was implemented as a convenience redirect without treating the `next` parameter as an untrusted user input at a security boundary.

---

## Contributing Factors

- `next` parameter added for UX without security consideration
- No input validation utility for redirect URLs
- No security review process for "simple" endpoint changes

---

## Fix Analysis

**What was done:** Added `startsWith('/')` validation — only relative paths are allowed. Falls back to `'/'` for invalid values.

**Was this a fix of:** `cause` — URL validation at the point of use

**Could the fix have been predicted?** `yes` — OWASP Top 10 includes unvalidated redirects

## Detection Gap

**How was this discovered?** `audit`

**Should this have been caught earlier?** `yes` — redirect with user-controlled param is always a security boundary

---

## Lessons Learned

Any endpoint that accepts a redirect URL parameter is a security boundary. Always validate that redirect targets are relative paths. Never trust user input in redirect destinations.

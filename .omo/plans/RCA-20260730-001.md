# Root Cause Analysis: `.gitignore` missing `.env*`

**RCA ID:** `RCA-20260730-001`
**Issue ID:** `ISS-20260730-001`
**Author:** Repair Agent
**Date:** 2026-07-30

---

## Summary

The project `.gitignore` was incomplete, missing `.env*` patterns. This left `.env.local` (containing `SUPABASE_SERVICE_ROLE_KEY`) unprotected from accidental commits.

**Root Cause Category:** `config`

---

## 5 Whys Analysis

| Why # | Question | Answer |
|-------|----------|--------|
| 1 | Why are secrets at risk of being committed? | `.env.local` is not in `.gitignore` |
| 2 | Why is `.env.local` not in `.gitignore`? | It was never added when the project was initialized |
| 3 | Why wasn't it added during project setup? | `create-next-app` only adds `.env.local` to gitignore for the `web/` subdirectory, but the root `.gitignore` was manually created later without env patterns |
| 4 | Why did the root `.gitignore` omit env patterns? | The `.gitignore` was created specifically for the Python package (photo-report-pdf), and the full-project gitignore was not reviewed |
| 5 | Why was there no review of gitignore coverage? | No engineering standards existed requiring gitignore audit for secrets |

**Root cause:** Project has a root `.gitignore` that was created for Python build artifacts, without considering secrets protection for the entire monorepo.

---

## Contributing Factors

- Root `.gitignore` was created ad-hoc for Python package build artifacts
- No `.env*` templates were reviewed during project setup
- No gitignore review is part of the development workflow

---

## Fix Analysis

**What was done:** Added `.env*`, `.env.local` patterns to root `.gitignore`

**Was this a fix of:** `symptom`

**Could the fix have been predicted?** `yes` — Standard security practice for any project with secrets

---

## Preventive Actions

| # | Action | Owner | Deadline |
|---|--------|-------|----------|
| 1 | Ensure CONSTITUTION.md requires `.env*` in `.gitignore` for all new projects | Sisyphus | 2026-07-30 |

---

## Detection Gap

**How was this discovered?** `audit`

**Should this have been caught earlier?** `yes`

**If yes, where:** During initial project setup — standard Next.js + Python monorepo gitignore checklist

---

## Lessons Learned

Never assume `.gitignore` coverage. Always explicitly add `.env*` patterns to the root gitignore in any project with secrets.

## P1 — Security

| # | Finding | Evidence |
|---|---|---|
| 7 | **Role checks live only in the UI.** `lib/auth/rbac.ts` is imported solely by `contexts/UserContext.tsx`. Every mutation route uses the **service-role** client + `requireProjectMutate`, which contains **no role check** (only `companyUserIds.includes(project.user_id)`). The RLS policies require `role IN ('foreman','site_manager','admin')` for defect writes and `site_manager/admin` for deletes — the admin client bypasses both. **A `client` or `photographer` in the same company can create and delete defects through the API.** | `web/lib/auth/rbac.ts:41,46`; `app/api/defects/route.ts:101,106,110`; `lib/api/company-auth.ts:155-184`; `20260731000001:148-181` |

| 9 | **Cross-tenant comments (read, write, delete).** Authorization runs on the **URL** `projectId`, while the write targets the **body-supplied** `entity_type`/`entity_id` — via the service-role client, so the scoped RLS in `20260827000001` is never exercised. ## Verified clean

- **TypeScript**: `tsc --noEmit` → 0 errors. **ESLint**: 288 files, 0 errors, 0 warnings.
- **i18n integrity**: all five catalogs have exactly **1055 leaf keys**, no key missing from any locale, no untranslated English in `mk.json`.
- **Auth**: 36/39 routes call `requireAuth` (server-verified `getUser()`, not `getSession()`); `health` + `verify` are intentionally public and whitelisted in `proxy.ts:21`, which independently 401s every other unauthenticated `/api/*`.
- **Validation**: no route calls `request.json()` directly — the only body parse is Zod inside `validateBody`. Zero string-built SQL; the one `ilike` pattern is parameterized by PostgREST. Mass assignment blocked by field whitelists.
- **Rate limiting**: every `POST/PATCH/PUT/DELETE` has `checkRateLimit` — the limited routes are GET-only.
- **Service-role key**: only `lib/supabase/admin.ts`; never imported by a client component/hook/context; no `NEXT_PUBLIC_` prefix.
- **Secrets**: `git ls-files` has zero JWTs, tokens or connection strings; CI uses placeholders; `.env.local` untracked and gitignored.
- **RLS**: `CREATE TABLE` and `ENABLE ROW LEVEL SECURITY` match 26/26; no `USING (true)` on tenant tables; `audit_logs` write policy is `WITH CHECK (false)`.
- **Storage**: bucket private, project-aware policies, signed URLs 1 h with `..` rejection and fail-closed normalization.
- **DB invariants that hold**: work-order status forward-only, attendance one-open-check-in + `check_out > check_in` + 24h cap, plan limits, coordinate range checks, `ON DELETE CASCADE` from projects to photos/logs/defects/work-orders/attendance/manifests/members.
- **Responsive**: all tables wrapped in `overflow-x-auto`; no fixed pixel widths on dashboard/project pages.
- **Dialogs**: Radix primitives (focus trap + Escape) everywhere except the hand-rolled `ProjectQRCode.tsx:230`.
